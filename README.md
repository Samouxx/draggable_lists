# Draggable Lists

> **Unofficial port to Minecraft 26.3 (Fabric).**
> This is a modified version of [Draggable Lists](https://github.com/mrmelon54/draggable_lists) by **MrMelon54**,
> ported by **Samouxx** in October 2026. The original mod stopped at Minecraft 1.21.8.
> Please report problems with this port [here](https://github.com/Samouxx/draggable_lists/issues), not to the original author.
>
> Changes from the original 1.0.15: ported 1.21.6 → 1.21.11 → 26.1.2 → 26.3 (new menu list layout, mouse events,
> unobfuscated game, new render pipeline package), NeoForge and Quilt builds dropped.
> The commit history of the `port-26.x` branch explains each change.
